# react-hello-world

Passaggi visti a lezione:
1. `npm create vite@latest react-hello-world` → scegli React e JavaScript
2. `cd react-hello-world` e `npm install`
3. `npm run dev` e apri l'indirizzo che compare (http://localhost:5173)
4. pulisci il codice di esempio (App.jsx, App.css, assets)
5. commit e push

Domande d'esame collegate: cos'è React (una LIBRERIA, non un framework), cos'è Vite (strumento che crea e serve il progetto), cos'è un componente.
